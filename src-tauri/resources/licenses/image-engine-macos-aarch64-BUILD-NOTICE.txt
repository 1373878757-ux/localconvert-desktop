Build notes:
This image-engine command-line sidecar is first-party Rust code for LocalConvert Desktop.
It supports --version, --self-check, local conversion between JPG/JPEG, PNG, and WebP,
aspect-ratio-preserving local resize, and same-format image compression for those formats.
Resize supports fit, width-only, and height-only modes, never upscales, and enforces
16,384-pixel edge and 64,000,000-pixel limits. Compression supports JPEG and WebP quality
values from 40 through 95 and lossless-only PNG optimization. JPEG and WebP orientation
metadata exposed by the decoder is applied before conversion, resize, or compression;
stale orientation metadata is not copied to the output.
The conversion, resize, and compression commands read only the requested local source image
and write only the requested task-owned temporary output path. The backend publishes a
collision-safe final compression output only when it is smaller than the source. They do not
contain upload, cloud, server, or telemetry code.
