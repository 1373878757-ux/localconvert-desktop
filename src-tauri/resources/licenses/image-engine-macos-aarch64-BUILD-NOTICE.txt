Build notes:
This image-engine command-line sidecar is first-party Rust code for LocalConvert Desktop.
It supports --version, --self-check, local conversion between JPG/JPEG, PNG, and WebP,
and aspect-ratio-preserving local resize for those formats. Resize supports fit, width-only,
and height-only modes, never upscales, and enforces 16,384-pixel edge and 64,000,000-pixel limits.
JPEG and WebP orientation metadata exposed by the decoder is applied before conversion or resize;
stale orientation metadata is not copied to the output.
The conversion and resize commands read only the requested local source image and write only the
requested collision-safe output path. They do not contain upload, cloud, server, or telemetry code.
