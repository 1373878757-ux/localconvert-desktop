# LocalConvert Desktop 60 秒演示脚本

**by 田宸宇**

目标：用一次连续录屏说明 LocalConvert Desktop 的当前 Preview 0.6.1 能力、纯本地定位与安全输出方式。不要在演示中声称 HEIC、Office、Windows、签名或公证已经可用。

## Before Recording

- 准备两个页数较少、内容可公开的 PDF。
- 准备一张 JPG 和一张 PNG；如需展示隐私清理，使用专门制作且不含真实个人信息的元数据样例。
- 将样例放在包含中文和空格的测试目录中。
- 保持 `converted` 文件夹可见，便于展示重名递增和不覆盖行为。
- 使用本地构建或从官方 Release 下载并完成 SHA-256 校验的应用。
- 关闭通知和任何可能暴露个人路径、用户名或文档内容的窗口。

## Timeline

### 0–8 秒：启动与定位

- 打开应用，短暂停留在品牌启动屏。
- 旁白：`LocalConvert Desktop，by 田宸宇。文件只在本机处理，不上传。`
- 主窗口出现后指出 qpdf 和 image-engine 已通过本地自检。

### 8–18 秒：文件导入与任务队列

- 将两个 PDF 和一张图片拖入窗口。
- 展示真实本地路径、任务选择和状态汇总。
- 旁白：`原文件不会被覆盖，所有结果写入源文件旁的 converted 文件夹。`

### 18–30 秒：PDF 工具

- 选择两个 PDF，执行合并。
- 完成后点击“打开输出位置”，让 Finder 定位结果。
- 快速指向拆分、旋转和页面提取入口，不必在 60 秒内逐项执行。

### 30–44 秒：图片工具

- 选择图片，执行一种 JPG/PNG/WebP 格式转换。
- 展示“适应范围 / 仅宽度 / 仅高度”和“不放大小图”。
- 快速指向 JPEG/WebP 质量压缩、PNG 无损优化和元数据清理说明。
- 旁白：`压缩后没有变小，或没有可清理元数据时，不会生成无意义的新文件。`

### 44–54 秒：报告与结果操作

- 展示成功任务的“打开输出位置”。
- 如已有失败样例，点击“复制错误信息”，展示“已复制”反馈。
- 导出 CSV 报告，然后点击“打开报告位置”。

### 54–60 秒：收尾

- 展示“清空记录”的二次确认，但点击“取消”，强调不会删除文件。
- 旁白：`纯本地、无上传、无服务器、无遥测。LocalConvert Desktop。`

## Recording Notes

- 录屏中只展示真实运行结果，不使用伪造成功状态。
- 避免放大错误日志中的完整本地路径；报告分享前应检查路径信息。
- 元数据清理应描述为“最佳努力”，不要使用“彻底清除”或“法证级”措辞。
- 当前公开构建只面向 macOS Apple Silicon，且尚未完成 Developer ID 签名与公证。
- 建议输出 1080p、60 秒左右的 MP4，并另截取 10–15 秒无声片段制作 README GIF。
