LocalConvert Desktop

by 田宸宇

纯本地、无上传、无服务器、无遥测的桌面文件处理工具。

在一个本地工作台中处理 PDF、JPG、PNG 与 WebP。文件不会上传，原文件默认不会被覆盖，已支持的操作无需转换服务器。

本地桌面工作台

为重视文件隐私的日常处理而设计

LocalConvert Desktop 面向需要批量处理 PDF 和常见图片的办公用户与个人用户。应用把转换、任务状态、结果导航和报告导出放在同一个克制的中文界面中，优先保证本地执行、可取消和安全输出。

当前能力

Preview 0.6.1 功能概览

只展示当前真实启用的能力，不把未来格式写成现有功能。

PDF 工具

使用内置 qpdf 合并、拆分、旋转 PDF，并抽取指定页面。

图片格式转换

支持 JPG/JPEG、PNG、WebP 之间已启用的本地转换方向。

图片改尺寸

支持适应范围、仅宽度和仅高度，保持宽高比且默认不放大。

图片压缩

JPEG/WebP 质量压缩与 PNG 无损优化；未变小时不发布输出。

元数据隐私清理

尽力清理 JPG、PNG、WebP 中常见的隐私元数据，不宣称法证级清除。

CSV / JSON 报告

导出任务状态和结果摘要，不包含文件内容或原始元数据载荷。

任务易用性

支持真实后台取消、打开输出与报告位置、复制精简错误，以及确认后清空界面任务记录。

Privacy by design

文件留在本机，输出保留边界

支持的处理由随应用打包的本地引擎完成，不要求账户、云存储或转换服务器。

  • 文件在本机处理，不上传。
  • 受支持的转换不依赖服务器。
  • 应用不采集遥测。
  • 原文件不会被覆盖。
  • 失败与取消只清理任务自有临时文件。
报告分享前请检查路径

CSV/JSON 报告可能包含本地文件路径，但不包含文件内容或原始 EXIF、GPS、XMP、IPTC 数据。

技术实现

桌面前端与 Rust 本地边界

前端只调用结构化 Tauri 命令；本地路径、任务生命周期、sidecar 进程和输出发布由 Rust 后端负责。

Tauri v2
桌面窗口、原生路径入口与打包
React + TypeScript
中文工作台、任务状态与报告交互
Rust backend commands
校验、队列、取消、超时和原子输出
qpdf sidecar
PDF 结构操作
image-engine sidecar
图片转换、改尺寸、压缩与隐私清理

当前边界

预览版限制

  • HEIC 转换、改尺寸、压缩和元数据清理尚未启用。
  • GIF、TIFF/TIF、RAW 图片处理尚未启用。
  • Office、视频和音频处理尚未启用。
  • Windows x64 与 Intel macOS 公开构建尚不可用。
  • 元数据清理是最佳努力，不是法证级彻底清除。
